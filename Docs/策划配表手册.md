# 《策划配表手册》

> **改表入口**：`ConfigWorkspace/Data/*.xlsx` ｜ **生效方式**：Unity 菜单 **Luban ▸ 表格数据导入**

### 一、配表铁律
1. **分工原则**：手感（移速、弹道抛物线、击退滑行、受击闪烁）去 Unity 调 SO 资产；**表里只填规则与数值**。
2. **符号禁区**：列表数组只用半角分号 **`;`**；标签掩码只用半角竖线 **`|`**。严禁逗号、空格。
3. **初始地块不用填表**：直接在 Unity 场景用笔刷绘制（`tile_initial.xlsx` 已废弃）。

---

### 二、核心表格

#### 1. `projectile.xlsx`（球种与元素属性）
| 列名         | 允许填值                                                     | 说明             |
| :----------- | :----------------------------------------------------------- | :--------------- |
| `id`         | `纯水`/`热水`/`冷水`/`干土`/`湿土`/`沙`/`粘土`/`冰种子`/`火种子`/`植物种子`/`电种子` | 球种（枚举别名） |
| `name`       | 字符串                                                       | 显示名           |
| `type`       | `水` / `土` / `地形种子`                                     | 元素大类         |
| `temp`       | **-6 ~ 6**（整数）                                           | 温度             |
| `wet`        | **0 ~ 6**（整数）                                            | 湿度             |
| `conductive` | **0** (无) / **1** (中) / **2** (强)                         | 导电性           |
| `tags`       | `无` / `含土` / `含沙` / `含植物`（多选加 `\|`）             | 元素标签         |

#### 2. `element_rule.xlsx`（元素反应规则网 · 核心）
> **匹配规则**：**自上而下匹配，首条命中生效**。调优先级请直接**在 Excel 中移动整行**（`priority` 仅作编号）。

| 列名                   | 说明                                  | 示例 / 规范                              |
| :--------------------- | :------------------------------------ | :--------------------------------------- |
| `priority`             | 规则编号（须唯一）                    | `1`, `2`, `3`...                         |
| `result_id`            | 生成的目标地块状态（枚举别名）        | `蒸汽`, `稀泥`, `燃烧`, `普通泥浆`, `无` |
| `effects`              | 伴生瞬间效果（`;` 隔开）              | `击退`, `滑行`, `击退;清除植物`          |
| `effectValuePos`       | 对应的效果档位号（1-based，`;` 隔开） | `1`, `2`, `1;1`                          |
| `requireTag`           | 落点格**必须包含**的 Tag              | `含土` / `含植物` / 留空                 |
| `excludeTag`           | 落点格**必须排除**的 Tag              | `含沙` / `含土\|含沙\|含植物`            |
| `requireTempMin`~`Max` | 触发温度闭区间                        | `-1` ~ `2`, `4` ~ `6`                    |
| `requireWetMin`~`Max`  | 触发湿度闭区间                        | `3` ~ `4`, `0` ~ `6`                     |
| `requireCondMin`       | 最低导电要求                          | `-1` (不检查), `2` (强电)                |

> ⚠️ 兜底行（`result_id = 无`）必须永远置于**最后一行**，新增规则插入在其上方。

#### 3. `tile_state.xlsx`（地块状态属性）
| 列名                             | 说明                     | 规范                                                      |
| :------------------------------- | :----------------------- | :-------------------------------------------------------- |
| `id`                             | 状态别名                 | `普通泥浆`, `稀泥`, `冰沙`, `基础水地块`, `空地` 等 19 种 |
| `duration`                       | 存活时间（秒）           | `-1` = 永久基础地块；`>0` = 动态地块（到期回空地）        |
| `canReact`                       | 是否允许继续参与反应     | 基础地块填 `TRUE`，派生地块填 `FALSE`                     |
| `temp` / `wet` / `cond` / `tags` | 地块自身自带的元素属性   | 动态地块全填 0，基础地块按设定填写                        |
| `effects` / `effectValuePos`     | 进入地块施加的效果及档位 | `减速` (pos `1`), `持续伤害` (pos `1`)                    |

#### 4. `tile_effect.xlsx`（效果数值库）
- 档位数由 `value1` 的分号分段决定（如 `0.5;1` 代表有 2 档）。

| 效果名称       | `value1` 含义              | `value2` 含义  | `interval` 含义        |
| :------------- | :------------------------- | :------------- | :--------------------- |
| **减速**       | 速度倍率（0.5 = 减速 50%） | 持续时间（秒） | —                      |
| **滑行**       | 滑行距离（格）             | 持续时间（秒） | —                      |
| **击退**       | 击退距离（格）             | —              | —                      |
| **麻痹**       | 麻痹时间（秒）             | —              | —                      |
| **瞬时伤害**   | 伤害值                     | —              | —                      |
| **持续伤害**   | 每次伤害值                 | —              | **伤害触发间隔（秒）** |
| **温湿度继承** | 温度继承比例               | 湿度继承比例   | 导电继承比例           |
| **清除植物**   | 清除十字范围（格）         | —              | —                      |

#### 5. `enemy.xlsx` / `player.xlsx` / `wave.xlsx`（关卡与数值）
- **`player.xlsx`**：`max_hp`（固定 **3** 血）、`invulnerable_duration`（受击无敌秒数，默认 0.8）、`attack_interval`（攻击 CD，默认 0.5）。
- **`enemy.xlsx`**：`hp`（普通怪 **3**，精英怪 **6**）、`max_speed`（追击极速）。半径 / 加速度 / 击退衰减 / 停止距离 / 脱战距离**已不在表里**，搬进了程序调参 SO `Resources/tuning/EnemyTuning.asset`（改表不会有反应，要调找程序）。
- **`wave.xlsx`**：`enemies_per_wave`（每波怪量）、`spawn_interval`（刷怪间隔）、`initial_delay`（首波延迟）、`respawn_delay`（波次间歇）。

---

### 三、改表 3 步防坑检查
1. **查符号**：没有用中文分号 `；`，列表无逗号。
2. **查档位**：`effectValuePos` 填写的数字不超过 `tile_effect` 中实际配置的档数。
3. **查导表**：Unity 中点击 **Luban ▸ 表格数据导入**，Console 无红字报错。
