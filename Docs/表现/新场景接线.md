# 新场景接线

## 必备 / 禁止
- 场景需：`GameRoot`、`InputProvider`、`PlayerController`、`CombatRoot`、`TilemapAdapter`、有地板的 Tilemap、主相机。
- 禁止：`Canvas`、`EventSystem`、第二个 `AudioListener`。UI 由 `UIMgr` 自动创建。
- 敌人**两条路都行**：运行时按波次生成（默认），或直接在场景里摆 `Enemy_<id>` 预制体实例 —— `CombatRoot.AdoptSceneEnemy` 会自动收养，不必手工登记。
- 参考现状：主场景 `Assets/Scenes/Official.unity` = `GameRoot` ＋ `InputProvider` ＋ `TilemapAdapter` ＋ `BoundsArea` ＋ 三层 Tilemap，再摆 `CombatRoot` / `Player` / 三个 `Fountain`（`kind` 0/1/2）/ `Virtual Camera` 预制体实例，外加一个手摆的 `Enemy_1`。

## 1. 场景
- 从 `Assets/Settings/Scenes/URP2DSceneTemplate.unity` 另存。
- **不加光源也能正常出图**（`Official.unity` 就没有任何光源；三个 `Slice_*` 沙盒里各有一个空物体叫 `Global Light 2D`，但都没有挂 `Light2D` 组件）。真出现精灵发黑时再加一盏 `Global Light 2D`。

## 2. Tilemap
- 建 `Grid`，子物体三层：`Ground`、`TileEffect`、`InitialSetup`。
- `Ground` 刷 `Tile_Floor`，至少一格。
- `Sorting Order`：`Ground=0`、`InitialSetup=1`、`TileEffect=2`。（**只有主场景对**：三个沙盒的 `TileEffect` 都是 `1`，`Slice_GridReaction` 的 `InitialSetup` 也是 `1` —— 见 `Docs/待办.md`）
- `InitialSetup` 可选；不画也行。**不建这一层就把 `initialSetupTilemap` 留空**（`Slice_CombatSandbox` / `Slice_PlayerFeel` 就是留空且没有该层）；建了就必须接进去。

## 3. GridView
新建 `GridView`，挂 `TilemapAdapter`：
- `groundTilemap` → Ground（必接）
- `effectTilemap` → TileEffect（必接）
- `initialSetupTilemap` → InitialSetup（可选）
- `stateTiles`：**保持空数组**（4 个场景现在全是 `stateTiles: []`），状态贴图自动走约定路径 `Assets/Resources/tiles/Tile_<TileStateType 成员名>.asset`
- 三层不能指向同一个 Tilemap。

## 4. BoundsArea（可选）
- `BoxCollider2D`：`Is Trigger ✓`，`Size` = 可走区域。

## 5. 玩家
层级：
```text
Player
└── View
```

`Player` 根：
- `Rigidbody2D`：Gravity Scale 0；Freeze Rotation Z；Interpolate；Discrete（敌人侧要求 `Continuous`，见《美术装配指南》§5.1）
- `BoxCollider2D`：Size (0.7, 0.7)，非 Trigger
- `PlayerMotor`：`body` 留空
- `PlayerController`：`motor` = 自身 PlayerMotor；`inputProvider` = InputProvider；`aimCamera` 可空；`boundsArea` = BoundsArea；`animView` = View 上的 ActorAnimationView

`View`：
- `localPosition` / Rotation 归零
- `SpriteRenderer`：任意色块
- `Animator`：可留空
- `ActorAnimationView`：`animator` / `spriteRenderer` 可留空；`useFlipX` 不勾
- `SpriteRenderer` 必须挂 `View`，不能挂 `Player` 根。

## 6. InputProvider 与 GameRoot
各建空物体，分别挂 `InputProvider`、`GameRoot`，无字段。

## 7. CombatRoot 与 Fountain
`CombatRoot`：
- `player` = PlayerController（必接）
- `gridView` = TilemapAdapter（必接）
- `ballRoot` / `actorRoot` / `fountains` 可空
- `enableWaves ✓`

`Fountain`：
- `CircleCollider2D`：`Is Trigger ✓`，Radius 3
- `spawnInterval` 1
- `landingRadius` 3 / `minLandingDistance` 0.8

## 8. Cinemachine（可选）
- 主相机加 `Cinemachine Brain`；建 `2D Camera`。
- vcam：`Follow` = Player 根；`Look At` 空；`Orthographic Size` 5；`Camera Distance` 10；`Damping` 0.15~0.3；`Aim` = Do nothing；Brain `Update Method` = SmartUpdate。
- 可选：`CinemachineConfiner`，`Confine2D`，`Bounding Shape 2D` = BoundsArea，`Confine Screen Edges ✓`。

## 启动验收
Play 后 Console 应出现：
```text
[Combat] 装配完成：格子 N 个（初始状态 0 个），球种 2 个，喷泉 M 个，敌人 启用
```
- 菜单态点 `BeginPanel` 的 `StartBtn` 开始。
- WASD 移动、Shift 冲刺、左键水球、右键土球。
- 检查：Player 下只有 View 且 localPosition=(0,0,0)；Player 根无 SpriteRenderer / Animator；ActorAnimationView 在 View；`useFlipX` 未勾；相机 Follow 拖 Root；Global Light 2D 存在；三层 Tilemap 不混用。
